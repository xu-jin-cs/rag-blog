# 示例语料 1：分片调优笔记（markdown）

RAG 知识库里，分片是检索质量的第一决定因素。切太碎会丢失上下文语义，切太粗会稀释相关度。

我们的生产实践中，旧逗号切分的碎片率高达百分之十三。所谓碎片，就是长度小于八字符的块，它们几乎无法携带完整语义。

解决分两步。第一步引入最小切长水位闸：累积段落超过二十六字符，才允许在分隔符处下刀，不足则并段继续累积，文档收尾不足的尾段强制并回前一块。这一步把碎片率降到零，块数减少四成三。

第二步把切分主口径改成句边界断句：只在句末标点和换行处切分。实测切点百分之百落在句边界，而逗号切分有四成五的切点在句中拦腰下刀。

所有分片参数必须回写配置真源文件。临时调参等于负债，下次自动重建即丢失。
